# openGym 定制版 1.6.9 / vivo 手表 0.6.15

手机 versionCode 55；手表 versionCode 30。基于已测试的 fork 提交发布，不在构建时自动 rebase 官方 main。

## 本次增强
- **AI 教练普通对话可提出计划调整**：不再仅限「复盘 → 改进计划」。问题可返回回答、澄清或结构化调整卡；支持继续修改方案。文字里的「应用方案」只打开确认，最终明确确认后才写入计划模板。
- **保护正在进行的训练**：教练调整只影响后续计划，不回写本场训练或历史。修订号、旧值校验、单待处理方案、幂等与决策 outbox 防止过期/重复应用。支持服务端、手机自带 Key 和演示模式；旧服务端回退只读回答。
- **vivo WATCH GT 训练交互**：点击动作名切换动作、圆点选择未完成组、大组数分页；点字段选中 → 表冠调值，再点打开数字键盘；Last time、指标页与统一结束确认。取消草稿不写入，增加会话/组/单位守卫与队列背压保护。方屏、圆屏分别提供原生签名包。
- **修复手表开练后的手机页面联动**：新建训练在持久化成功后导航训练页；重放/重复消息不抢页面。此项不是 Android 后台强制拉起 Activity 的实现。
- **日历本地日期边界修复**：避免部分时区在月初选择 ISO 日期时退回上月。

## 安装
- Android：`openGym.apk`（沿用本仓库正式手机签名）。
- vivo WATCH GT 方屏：`opengym-watch-0.6.15.rpk`。
- 支持的圆屏 BlueOS：`opengym-watch-round-0.6.15.rpk`（不是 Wear OS/Apple Watch 安装包）。
- 每个安装包附 SHA-256 文件。建议先导出备份，再更新手机和手表；不要卸载旧版以免丢失本地数据。

## 测试与边界
- 本地前端分批回归覆盖 496 文件 / 6059 个唯一测试；Vite 生产构建、18 语言 / 2619 key、严格文案检查通过。新增标签中部分非中文语言仍用显式英语 fallback，并非全部译文已完成。

- Windows API 的 6 项 POSIX 权限用例不以跳过处理，必须由本次 Linux 门禁验证；实际结果见本版本 GitHub Actions。
- 尚无手机/手表真机验收；后台、锁屏和杀进程开练联动未验证。手表示范媒体、新 skip/hold 协议未启用，不能按已上线能力理解。
- 本次 GitHub 发布**不等于后端已部署**。服务端模式的教练可执行方案和 Webhooks 需部署匹配 API；手机自带 Key 模式不依赖该服务端新接口。
