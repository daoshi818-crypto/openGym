# openGym 1.6.34 / WATCH GT 0.6.37

修复手表重装后出现重复设备记录、手机训练启动同步慢，以及两端不同训练无法正确处理冲突的问题。

- 手机连接页只显示当前连接状态，取消历史安装列表和设备选择。先探测 vivo 运动健康当前通道，收到匹配的随机编号与安装身份回执后，才显示“已确认连接”。重装后的新安装自动接管当前通道，旧安装的待传数据继续隔离。
- 手表首页和训练状态栏显示“手机已连接／手机未连接”。连接确认会定期刷新，超时或断开后不继续显示已连接。
- 手机已有训练、手表还有另一场训练时，手表只提供“保存手表训练”和“放弃手表训练”。手机当前训练不结束、不保存、不替换，也无需手机侧再操作。
- 保存手表训练时，完整冻结当前组记录与统计，写入关闭日志，再由手机正常保存历史；手机持久保存成功前，手表显示等待确认。放弃则关闭手表训练，之后接收手机当前训练。断连、存储失败和重启保留待处理记录。
- 手机主动发现已打开的手表应用，不再依赖手表重新打开。双方协商后，小快照最多 4500 字节走单包持久确认，大计划继续可恢复分片；重复探测不会重置分片进度，新训练可直接接替旧训练的过期显示快照。

配套安装：手机 `openGym.apk` **1.6.34（80）**；390×450 方屏 `opengym-watch-0.6.37.rpk` **0.6.37（52）**。圆屏继续附带 **0.6.31 legacy**，不包含本次新交互与协议能力。请配套更新手机和方屏手表端。

沿用已有官方 Wear OS 视觉映射，冲突框使用现有组件并修正方屏居中。本次不增加音乐控制等无关功能。

已有自动回归、原生编译、签名校验与 390×450 编译模板预览；尚无 WATCH GT 真机连接，实际耗时、蓝牙环境下表现和长时间稳定性需按验收步骤实测。
