# openGym 1.6.40

本版恢复训练中重量、次数的即时双向同步。每次编辑只发送对应字段，连续编辑合并为该组该字段的最新值；连接中断时丢弃实时修改，不进入待上传队列，也不在恢复连接后补传。完成组消息只标识完成的组，增删组仍按结构事件同步。

WATCH GT 旋钮关闭系统默认的旋转触感，保留短促手动反馈并降低触发频率。振动 API 不提供强度档位。

手机版本：1.6.40（versionCode 88）。方屏手表版本：0.6.42（versionCode 61）。圆屏手表继续使用已签名验证的 0.6.31 包。

自动化验证覆盖手机和手表通信边界、实时字段传输、离线不排队、完成组事件和旋钮交互；正式构建由发布工作流完成签名、包内容校验及 SHA-256 校验。
