# OpenGym 1.6.26 / BlueOS 手表 0.6.29

本版将此前完成的手表 UI 整理与文字裁切修复打包发布。手机 1.6.26（72），手表 0.6.29（44）；手表提供方屏与圆屏两个包。

## 本版变化

- 训练主屏、休息倒计时、重量和次数编辑均固定一屏，不使用滚动列表。重量编辑的减加与完整数字键盘均显示取消、保存；其他详情和操作页面允许滚动。
- 完成、撤回及暂停按钮保留纯矢量图标，64px 触控区；组圆点触区 48px，五组以内完整展示，更多组分页。
- 保留上次训练小字摘要及原点击详情逻辑，训练统计与放弃训练确认继续可用。
- 修复 kg 尾部和重量/次数文字的纵向裁切：数值保留原字号，增加行框余量，单位采用完整行高，并容纳字段选中边框。新增实际字形基线边界检查，补足此前仅查横向裁切的遗漏。
- 首页、动作列表、评分、结束/放弃确认和总结的文字及按钮重新分配空间，避免长名称、数值与相邻操作挤压。
- 修复原厂编译器不支持首页同一节点同时声明 `for`/`if` 的兼容问题，改为等价的条件列表数据源，恢复训练时隐藏其他计划的行为不变。

沿用 1.6.25 / 0.6.28 的切组定时器及手机休息状态校正，不重写训练同步协议或持久化队列。此版手机功能无额外变动，配套 APK 使用相同发布流程生成。

## 验证边界

发布准备阶段手表专项 42 个文件、552 项测试通过；390×450 方屏与 466×466 圆屏各 48 个浏览器预览场景通过，包括 kg/lb/秒、选中边框、已完成组、长数字及编辑页面，并额外以实际编译模板重复检查通过。方屏和圆屏均完成原厂 BlueOS 编译并通过编译输出的布局合同、包清单与 SHA256 校验，嵌入签名证书身份与 0.6.28 相同；GitHub 发布前运行完整前端/API及手机启动检查。

浏览器预览、原厂编译和自动化测试不能替代实体手表验收，本版尚未真机验证。升级后重点检查连续切组、完成/撤回、动作边界、手机跳过休息，以及重量调整与单位显示。
