# 1.6.7 手机启动黑屏修复

手机版本 1.6.7（versionCode 53），手表仍为 0.6.14。

## 原因与复现

1.6.6 合入万圣节主题时，App 的 Shell 引用了当前分支不存在的
`permSteps`。已有本地用户启动时、首次使用者选完本地模式后，都会执行
到该表达式，抛出 `ReferenceError: permSteps is not defined`，导致 React
卸载主界面。位于 Shell 内部的页面错误边界无法捕获父组件自身的异常。

使用 1.6.6 的生产移动包资源，在 412×915、简体中文的 Chromium 浏览器中
复现了上述错误及空白 body。首次引导可显示，点击“在此设备上使用”后变空白。

## 修复

删除不属于当前分支的权限引导条件，保留已登录、本地首次引导与训练界面的
既有显示控制。没有数据迁移，不删除任何本地状态；可通过相同正式签名覆盖升级。

新增 `App.startup.test.jsx`，实际渲染完整 App，覆盖已有本地用户与结束首次引导
两个场景。修复前两项均因同一 ReferenceError 失败，修复后通过。原有测试主要
验证登录前启动与单个模块，生产构建也不会检查这种未声明变量，漏掉了这个问题。
