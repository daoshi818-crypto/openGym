# openGym 定制版 1.6.12 / vivo 手表 0.6.18

手机 versionCode 58；手表 versionCode 33。本轮修复教练聊天方案格式兼容、输入法布局和 GT1 三处显示问题。GT1 使用不带 round 的方屏 RPK；覆盖安装前建议备份训练数据。

## AI 教练
- 聊天输出使用专用整数 schema，不再复用允许任意类型的复盘 after 字段；补充裸整数与“除了第一个动作，其余三组”的输出规则。
- 对非严格模型返回的数字字符串或仅有对应字段的单键对象进行无损规范化；仍拒绝含糊文字、小数、越界、额外字段和相对增减。组数仍严格为 1–10，目标动作、范围、过期状态、用户确认等安全校验保留。
- 回归原话“我想把练背除了第一个动作以外 其他改为三组”：测试夹具经过模型调用边界、方案校验、确认应用后，首个动作和其他训练不变，其余三个动作变为 3 组；当前训练与历史不被改写。此测试不等于已对用户实际提供商做在线复现。
- 修复输入法同时缩小窗口和可视区域时漏判键盘打开的问题；区分横竖屏变化，聊天区自行滚动；全局输入框避让不再重复滚动整个教练页面。

## GT1 390×450 三处显示修正
- 已完成组：撤销提示合并到组状态行，不再额外占用一行；重量/次数、Last Time、撤销按钮、RPE/RIR、组圆点和底部入口在一屏内展示。撤销行为与已完成组编辑保护不变。
- 精确键盘：使用独立紧凑布局，编辑字段/单位/组号合并到顶部；保留两行动作名、当前数值、完整 12 键、返回减加、取消和保存。按键至少 44px，保存/取消 48px，无需向下滚动找按钮。
- 编辑目标发生变化时，提示替换键盘顶部信息，不增加整页高度；原保存拦截规则保留。
- 首页：压缩顶部与启动区，开始按钮从 104px 调整到 88px。即使显示“最近训练结果”，第一张训练卡片的两行名称和两行动作摘要也能完整展示；多计划仍可滚动切换。

## 验证与边界
- 新增布局回归：标准当前组、已完成组、数值编辑、精确键盘不能依赖列表滚动；第一张计划卡片必须完整落在列表可视区。旧版三处问题均已通过该检查复现。
- 32 个 390×450 代码生成预览场景通过边界检查，覆盖次数键盘、长动作名/失效提示、长计划名/最近结果。
- 本地 watch 回归 27 文件 / 337 项通过；方屏和圆屏均通过厂商原生编译与编译后布局合同检查。
- 教练相关 API 定向回归 122 项通过，聊天确认应用与键盘定向回归 53 项通过；浏览器模拟覆盖安全区、窗口缩小、覆盖式键盘和反复开关。浏览器模拟不等于 Android 真机输入法验收。
- 手机内置 / BYOK 教练使用随 APK 更新的共享核心；使用独立自建教练服务器时，服务器也需更新至本次代码，单独安装 APK 不会替服务器部署更新。
- 预览不是 GT1 真机截图，固件字体和真实触控/表冠仍需安装验收。长历史、动作列表等页面继续保留必要滚动，不把全应用强行锁成一屏。
