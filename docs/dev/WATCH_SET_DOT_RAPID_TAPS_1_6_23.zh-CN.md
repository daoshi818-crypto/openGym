# 手表组圆点连点保护（0.6.26 / 配套手机 1.6.23）

## 证据与边界

反馈：同一动作快速点击组圆点，画面收缩、黑屏后退出到表盘。当前未连接物理手表，缺少原生异常、内存和看门狗日志，不能确定退出的唯一原因。

代码与可复现回归确认两条压力路径：点击当前组也进行会话写盘并追加 focus 事件；普通刷新和同步回执刷新会替换整排圆点对象，模板没有稳定重复节点标识。既有原子提交只能阻止重叠写入，不能消除连续无效提交和节点重建。

## 本次处理

- 圆点 key 由 sid、动作实例 ID、组 ID 组成，传入原生 repeat 的 tid。相同节点仅更新变化的状态，不替换数组和对象；结构或身份变化才替换。
- 按稳定 ID 判断当前组，重复点击直接返回。不能用旧数组下标推断同一组，也不能在目标已删除时退回邻组。
- 120ms 安静期内，只保留最后一个未提交的切组目标。输入仅复制原始身份字段和点击时 baseCommitRev，不持有响应式圆点对象或原生事件。
- 调度器最多一个计时器、一个在途写入、一个待处理目标和一个批次 Promise。慢存储期间不启动第二个写入；当前写入完成后再处理最终目标。
- 只有提交前的焦点意图可合并。已经落盘的 focus、完成、字段等事件不删除、不改 ID，继续走现有精确确认与重试路径。
- 延迟执行再次验证会话、动作、目标组、暂停、休息、页面及积压状态。因果版本不因新手机快照到达而重写，仍由手机优先裁决。
- 隐藏、销毁、结束或换训练取消尚未提交的意图，不撤销已经接受的持久写入。切组未完成时，其他本地游标与完成操作不能作用于旧组。
- 不改变 CSS、触摸区域和界面布局，不重写手机业务或同步协议。直接手动切动作、撤销仍保留已有的自动焦点锁例外，只增加待切组保护。

## 验证范围

自动化覆盖：200 次瞬时连点、1,000 次持续连点、当前组重复点击、最后点击返回当前组、慢写盘、取消后重入、存储失败重试、旧下标、目标删除、暂停/休息、手机快照插入和手机焦点优先；编译后模板检查 tid 和原有布局约束。

JS/SDK Page 代理测试不模拟原生渲染器。原生编译通过也不证明真机系统级黑屏已经消失。

## 真机复测

使用两个动作、分别五组和两组的训练，确认手表实际版本为 0.6.26。

1. 第一动作内反复快速点击不同圆点；停止后应只选择最后一个仍有效目标，无黑屏、退出或持续卡住。
2. 重复点击当前组，不应反复触发同步或回退到其他组。
3. 快速切组后点击完成；尚未提交时不能误完成旧组，选择落地后应完成所选组。
4. 从第五组完成、跳过休息进入第二动作；切回已完成组并撤销，检查两端对应行状态。
5. 连点期间离开训练页、手机结束训练、重新开始新训练；旧切组任务不能改变新会话第一组。
6. 断连后连点再重连，确认最后焦点与已保存训练数据恢复；两端同时切组时确认手机优先且不弹冲突提示。

## 手机导出诊断日志

入口：设置 → 集成 → vivo BlueOS 手表 → 导出诊断日志。手表连接、发送计划和诊断也集中在集成页，不再分散在训练设置或跳转到计时提醒。无需开启开发者模式或先开始新训练，导出 JSON 通过系统分享保存或发送。

手表记录 app_start/app_destroy、页面显示/隐藏/销毁、组圆点点击及计数、切组提交、通用本地提交耗时/失败、RPC 收发、SDK 超时/失败、received/committed 回执。只记录会话/动作/组身份、版本和状态元数据，不记录完整训练、重量/次数、心率、账号或令牌。

手表日志为独立存储键 watch_diagnostic_log_v1，最多 64 条、24 KB，最多每秒一个写入且只允许一个在途写入。相邻 250ms 内同类事件合并计数；不按每次连点写盘。日志存储失败或回调超时后本次进程停止写盘，保留内存记录，不能改变训练提交/重试。已完成落盘的记录跨应用重启保留，启动标记带 boot 身份。突然退出可能丢失最后约一秒，存储忙或失败时可能丢失更多；onDestroy 缺失不能单独证明崩溃。

手机保留最多 160 条同步业务元数据（500ms 批量本地保存），导出时合并原生 SDK 内存日志和版本/队列信息。日志收集使用独立 watch_log_request/watch_log 命令，固定请求 ID 和偏移，冻结只读快照分页，每页最多 12 条且不超过 5500 UTF-8 字节；丢页只重试一次，不连接、不 checkpoint、不生成训练回执、不进入持久训练队列。

请求失败仍导出手机日志，状态为 timeout/partial/unavailable/invalid_reply；上次成功取回的手表日志单独标注 collectedAt，绝不冒充当前响应。新手机配旧手表也只能超时降级，不能因此影响训练。

若再次黑屏：记下触发时间，重新打开手表应用并连接手机后立即导出，不必重新开始训练。若无法重开，先导出手机侧记录。保留表型/固件、安装版本及 BlueOS 系统崩溃日志；应用日志无法获取原生堆栈、OOM 或看门狗转储，不能替代系统日志。
