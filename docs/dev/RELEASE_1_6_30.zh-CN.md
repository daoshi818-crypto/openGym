# OpenGym 1.6.30 / 方屏手表 0.6.33

提供正式签名手机 **1.6.30（76）APK**、vivo WATCH GT / BlueOS 方屏 **0.6.33（48）RPK**。请同时升级手机和方屏手表，新事件依赖压缩在双方协商后启用。圆屏继续附上 **0.6.31（46）旧兼容包**，不改变其版本或原始内容。

## 本次修复

- 根据 11 月 19 日真机日志定位训练页 JavaScript 堆耗尽。训练会话移出响应式代理，显示列表和触摸坐标复用对象，HR 采样只读取必要字段，减少训练过程中持续增长的分配和保留。
- 横向页面保留有界原生子树，减少滑动时反复创建/销毁。旧训练回执不再驱动当前训练页重建。
- 表冠兼容直接和 detail 包装事件；渲染后重新获取一次焦点，退出时清理。未选重量/次数时不再启动无效存储事务。新增有界诊断，便于区分未选中、未收到表冠和提交失败。
- 历史摘要、长名称等显式采用官方省略规则，避免 BlueOS 默认硬裁断；底部箭头向内收，降低物理圆角裁切风险。
- 依用户要求，**整个音乐控制页已删除**，横向仅保留概览、当前组、统计三页；同时删除其接口及独占资源。移除官方概览没有的加组、减组、暂停、末组评分及历史/诊断点击入口。
- 新旧协议均保留可靠持久化和精确业务回执。新协议使用因果前沿，手机从持久决策验证祖先，避免直接压缩依赖造成连续训练冲突；不重写或删除已接受的旧事件。

## 验证与限制

验证数字及最终发布结果以本页随发布更新的记录为准。专项包含真实 .ux 脚本、BlueOS Page 契约模型、连续 5+2 组、新旧协议、断连积压、代理对象保留和表冠回归。原生编译检查三页 show、显式 ellipsis、移除音乐入口，并验证签名、资源摘要和版本。

这些检查不等于真机 FPS 或稳定性测量。**没有编造真机 30 分钟、内存下降比例或“零闪退”数据。** 表冠的真实固件焦点及滑动稳定性仍需安装本版后复测。

官方设计来源仍为最新 v1.4.5，但本版**尚不是整套官方 UI 百分百复刻完成版**：开始倒数、称重、计时保持、修正组、热身/单双侧/超级组、完整心率曲线及原生动效仍有差距。音乐是用户明确要求删除的例外。

详细证据、文件位置、复现方式、风险、真机测试步骤及后续阶段见 [0.6.33 故障分析与修复记录](https://github.com/daoshi818-crypto/openGym/blob/v1.6.30/docs/dev/WATCH_DEVICE_FIX_0_6_33.zh-CN.md)。原始诊断和照片未上传。
