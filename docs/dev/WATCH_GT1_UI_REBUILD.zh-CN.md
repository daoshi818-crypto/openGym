# GT1 390×450 UI 重构与验收（手机 1.6.12 / 手表 0.6.18）

## 0.6.18 一屏适配补充
- 已完成组的撤销提示并入组状态行，不添加独立提示高度，标准当前/已完成组均不需滚动。
- 精确键盘单独使用紧凑间距、顶部合并字段/单位/组号；全部按键、返回减加、取消/保存同屏。按键至少 44px；长动作名支持两行；失效提示替换顶部行，不挤走底部按钮。
- 首页启动圆按钮改为 88px，减少顶部留白；有最近结果入口时仍预留完整两行计划名称+两行动作摘要的卡片空间。仅多计划列表需要滚动。

## 本轮范围
- 完整重写 `Index`、`Workout`、`ExerciseList`、`Keypad`、`Summary` 的模板与样式，清除旧固定高度外壳、旧紧凑样式叠加和动作演示。
- 对照已确认的 V3 大字六屏和 V4 Last Time / 结束三屏设计。以 Apple Watch 视觉层级为主，叠加 Apple 风格组圆点及 Wear OS 风格点击动作名切换；不声称其他系统原生控件在 BlueOS 上像素级相同。
- 根页面与主内容容器宽高 100%，黑色背景铺满。标准安全内容宽 338px，列表卡片宽 358px。390×450 为发布前校验尺寸，不再用 350×414px 固定外壳。

## 页面与操作合同
| 页面/状态 | 展示 | 操作及保护 |
| --- | --- | --- |
| 首页 | 当前计划、圆形开始按钮、可滚动计划列表、真实同步状态 | 先选计划再开始；活动训练恢复原会话；手机训练冲突需确认，不静默覆盖 |
| 当前组 | HR/时间、大动作名、组号/计划、横排重量×次数、Last Time、圆形完成、RPE/RIR、组圆点 | 点标题进入动作列表；圆点只选未完成组，不标记完成；点大绿按钮完成并休息；已完成组支持撤销 |
| 圆点分页 | 当前白描边、已完成白实心、待做深灰实心，44px 触控区 | 大量组有前后窗口；翻窗口不变组；使用稳定会话/动作实例/组 ID 防止误改 |
| 字段编辑 | 点字段选中高亮，再点进入大数字编辑页 | 主训练页表冠即时保存选中字段；编辑页表冠/减加/键盘共用草稿，取消不写入、保存才提交；目标已删/完成/暂停/休息则拒绝过期编辑 |
| 休息 | 当前动作、104px 倒计时、下一组名称/组号及处方、上一组强度 | ±15s、跳过；表冠保持既有 5s 步进；倒计时使用绝对截止时间，评分不暂停休息 |
| 动作列表 | 当前动作高亮、完成/总数、独立展开按钮、各组处方 | 点动作名切换到该动作未完成组；展开不切动作；点组可回看已完成组；保存/返回/放弃固定在底部，放弃须确认 |
| 训练操作 | 已用时、HR/热量、完成量、当前处方、加减组、暂停/继续 | 原生列表可滚动；返回当前组不跳到别组、不标记完成 |
| Last Time | 仅真实历史工作组，摘要和可滚动详情 | 只读，不复制到当前组，不发送训练编辑事件；无历史不造数 |
| 强度 | RPE 或 RIR，大数字、减加、表冠、语义说明 | 目标组身份固定；RIR 0 必须显示为 0；保存/清除只改目标组；手机关闭量表不保留错误入口 |
| 结束入口/确认 | 绿色旗帜、真实完成组数、末组评分、继续训练 | 旗帜只发起确认；确认保存已完成组，不补完未完成组；全部完成也不静默结算 |
| 总结 | 单页左对齐滚动，时长/组数/训练量/HR/估算热量/同步状态 | 缺失值不伪造；完成只返回首页，不再次结算；待手机确认与已同步状态分开 |

## 尺寸与溢出策略
- 标准当前组：顶部 52px、内容 336px、底部操作区域 62px，总计 450px。训练内容区 `flex:1; min-height:0`，列表高 100%，底部独立，不被长内容挤走。
- 标准休息状态主要操作一屏可见；长名称和异常长文案继续通过列表滚动。主数值按位数采用专用降级字号，不裁掉数字或单位。
- 动作列表独立可滚动容器也设 `min-height:0`。首页有最近结果入口时仍保留可触摸的计划滚动区域。
- 总结、历史、精确键盘内容超长时滚动，不把整页缩小。圆屏保留独立安全区与另包，但编译通过不代表圆屏真机验证通过。

## 删除动作演示
- 删除手表媒体客户端/格式/播放模块、Workout 媒体状态和入口、RPC 专用媒体分发、文件能力声明。
- 删除手机 WatchMediaPlugin 和注册、JS 媒体响应器、计划中的 mediaRef。训练协议、持久事件队列和手机原动作视频保留。
- 旧版缓存不主动清除，避免删除训练相关数据。新版本不读取/请求旧媒体。建议手机和手表同时覆盖升级，避免旧手表继续向新手机请求已删除功能。

## 自动验证方式
1. `watch-app/scripts/build-release.ps1`：厂商编译器构建方屏/圆屏，校验 VRU、签名条目、版本、目标设备、SHA256。
2. `watch-app/scripts/verify-layout.cjs`：检查编译后模板/CSS 的全屏根、原生滚动、450px 高度预算、圆点/完成按钮触控尺寸及导航合同。
3. `watch-app/scripts/preview-gt1.mjs <目录>`：从编译模板和实际 UX 样式生成预览，数据通过真实脚本与会话模型生成。
4. `watch-app/scripts/capture-gt1.cjs <目录>`：以 390×450 浏览器语义适配捕获 32 场景，检查根尺寸、固定操作边界、横向溢出与主要数字裁切，并拒绝标准当前/已完成组及编辑/键盘页需要滚动、第一张计划卡片截断。设 `PLAYWRIGHT_MODULE` 可指定 Playwright 安装位置。
5. frontend watch 回归与完整 Vitest、mobile 启动测试、手机 production bundle/Capacitor 同步、Android Java 编译；GitHub 门禁通过后再发布 APK、双 RPK 及校验文件，最后更新 update.json。

## 必须保留的真机验收边界
**浏览器语义适配不等于 BlueOS 模拟器，也不是真机截图；尚未确认固件字体、触控传播、表冠事件与睡眠唤醒表现。**

GT1 安装后需检查：
1. 手机与手表一起覆盖升级，历史和计划保留，不出现示范入口、不发送图片帧。
2. 首页空态/多计划/最近结果、当前组/无历史、两行动作名、字段编辑/键盘、休息、评分、历史、动作列表、结束确认与总结均铺满黑底，底部操作无裁切。
3. 圆点点一次切换正确未完成组；已完成圆点不改组；在动作列表回看完成组可撤销；大量组分页不误切。
4. 点动作名一次打开列表，选动作一次切换；滚动结束的尾随点击不误选；返回保持正确组身份。
5. 点选字段后表冠只改该字段；编辑取消不改值；保存及手机双向同步正确；休息表冠只改休息。
6. RPE、RIR 0、关闭量表；休息中评分；末组评分；全部完成/手动提前结束/放弃及冲突确认均正确。
7. 总结真实显示已保存/待确认，不出现假 PR、缺失 HR 假值或重复结算。
8. 断连/重连、手机后台或进程被杀、手表锁屏/抬腕分别验证。手机不在运行时不承诺从手表强制拉起 Android Activity。
