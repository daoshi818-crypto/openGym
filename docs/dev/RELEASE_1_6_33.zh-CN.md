# openGym 1.6.33 / WATCH GT 0.6.36

重量、次数采用官方 Wear OS 的同页草稿输入方式，并修复回执发送拖住业务队列、旧快照迟迟不能让位的问题。

- 先点选重量或次数，再转表冠；再次点已选字段，在训练页内显示官方十二键数字键盘。取消返回当前组，不再打开独立编辑页面。
- 表冠和键盘仅更新当前组草稿与显示。点完成组时，把最终重量、次数和完成事件一起保存；不再每转一格写入完整训练状态、发送重量/次数事件。
- 业务处理和回执发送分开。回执丢失或发送超时后，手表按原事件重试，手机重放已保存的准确结果，后续业务不等待前一回执发送完成。
- 双方协商后，切组、休息采用细分依赖；生命周期、结构修改、完成与撤回等必要顺序仍保留。旧版事件保持原依赖。
- 双方协商后，同通道旧分片任务连续三次到期重试仍无进展，允许最新全量快照接替。手表先持久保存代次水位，再回执；迟到的旧分片无法覆盖新代次。
- 确认回滚的业务异常重试三次后保存原事件并明确拒绝；手表保留未解决记录。磁盘写入失败仍等待恢复，不冒充成功。

配套安装：手机 `openGym.apk` **1.6.33（79）**；390×450 方屏 `opengym-watch-0.6.36.rpk` **0.6.36（51）**。圆屏 `0.6.31（46）` 继续作为旧兼容包提供，不含本次改造。

保留具体已绑定手表选择、双向连接确认、全量计划目录和今日训练计划；音乐入口继续移除。本次沿用已有官方来源视觉与方屏比例，未声称全部官方 UI 已百分百复刻。

验证和限制：实际源码自动回归、BlueOS 原生编译与签名验证、SDK 字体的 80 个 390×450 编译模板预览场景分别检查；桌面预览不能证明真机无死机。输入草稿在切换目标/单位、训练暂停/休息/结束或页面销毁时失效；未完成组前尚未持久化，强退可能丢失未提交输入，与官方当前组草稿模式一致。
