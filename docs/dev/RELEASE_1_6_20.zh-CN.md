# openGym 定制版 1.6.20

手机 **1.6.20 / code 66**；BlueOS 手表 **0.6.23 / code 38**（方屏、圆屏）。请一起升级双端，保留应用数据。

## 本次修复
- 手表跳过休息后，手机保留操作来源，避免把手表事件回传成新的手机编辑，减少快速完成/跳休息时的假冲突和状态回退。
- 同一训练中的字段分歧自动以手机为准，不再要求用户选择保留哪一端，也不弹出同步冲突警告。训练页继续显示真正的离线、待传、存储失败等状态。
- 手机快照早于否决回执到达时，在可靠存储事务中重建手表状态，撤掉被手机否决的本地覆盖，保留其他未确认操作与心率；没有足够新的快照时自动请求补齐。
- 精确的手机裁决只结束对应事件，后续操作独立验证；手机修改的值受保护，不因消息捆绑其他字段而被覆盖。
- 兼容原有确认协议、离线事件和旧冲突记录；历史记录保留，旧提示不再误导用户。保留上一版的新训练隔离、BlueOS 代理提交和组圆点点击修复。
