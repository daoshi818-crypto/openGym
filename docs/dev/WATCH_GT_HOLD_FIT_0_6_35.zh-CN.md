# WATCH GT 0.6.35：结束操作与 390×450 适配

## 本次范围

用户真机反馈：按住结束停在约七成绿色，随后放弃训练也不可用；休息页下一组重量次数被底部截断，并要求检查全部页面。用户明确目前卡顿已消失。

以 390×450 方屏为目标，保留现有官方来源的颜色、页面顺序、按钮形态及业务功能，调整组件比例、原生文字行框和安全边距。本次没有宣称完成全部官方 Wear OS UI 的百分百移植，也没有拿浏览器预览代替真机验收。

## 结束与放弃的根因和改动

`watch-app/src/Workout/index.ux`：

1. `flushRestNudge` 把提交 Promise 写入响应式 Page 字段。原生代理会改变对象身份，`finally` 的严格相等判断不能可靠清理；后续结束再次等待代理 Promise 可失败。待提交任务现放在 `staticData.sessionModel.restFlush`，通过 `restFlushOf` 访问原始对象。
2. 根 `touchCancel` / `touchEnd` 和切换“放弃训练”未统一清理长按。现统一取消进度和截止计时器，返回、隐藏、销毁亦清理。取消后旧长按不会继续保存训练。
3. 原先结束触发依赖每 50ms 的绘制进度回调。现保留 1000ms 长按，使用独立截止计时；进度以 100ms 更新整数百分比。若原生计时回调延迟，松手按实际时长兜底，且只执行一次结束。
4. 变化的绿色填充上方增加固定、全按钮尺寸的触摸层，避免增长的填充成为新的触摸目标。填充仍保留现有双色文字视觉。
5. 关闭失败后释放保存锁，并在结束区域保留错误提示，周期连接状态刷新不会覆盖它；可继续训练或重试、放弃。真实保存仍必须先经过本地持久化事务，离线也可结束，不等待手机联网。

`frontend/src/lib/watch-finish-hold.test.js` 使用实际 `.ux` 脚本、实际会话/关闭日志模块及原生 Page 代理契约；修复前六项用例中四项失败，涵盖七成进度取消、切换放弃与调节休息后的结束失败。此类回归验证代码路径，不是硬件故障的完整复刻。

## 全页面尺寸检查

- Workout：固定内容区 y=44…400（356px），分页点 y=414…426。当前组输入框降为 120px、主要操作降为 64px；两行名称、提示、历史与已完成评分保留独立预算。
- 休息：按最小原生尺寸相加，倒计时、进度条、操作、评分和下一组共 354px，放入 356px。下一组动作名保留两行，组号及重量次数单独排在底行；15:00 和较长数值有边界测试。
- Index：滚动窗口保持 y=48…402，宽度收至 336px；今日卡片、计划列表、空态、恢复与冲突确认沿用各自流程。
- Keypad：顶部留 30px、底部留 28px；头部 334px、保存按钮 304px，错误提示两行时十二个按键仍有明确高度预算；快速编辑的长数值降低字号。
- ExerciseList：标题、222px 列表和 122px 底部操作区分别定高，防止滚动内容盖到结束/返回/放弃按钮；保留完整动作名与组详情。
- Summary：326×370px 滚动区放在 y=40…410，成对统计各占 146px；长统计值单独缩小字号，底部“完成”可滚动到。

`verify-layout.cjs` 检查实际 BlueOS 编译模板及上述纵向预算，禁止靠浏览器 flex 缩小倒计时父框来掩盖原生溢出。`preview-gt1.mjs` 支持用本机 SDK 的 HanyiVar-vivo-60S/70S 字体生成预览，不把字体加入发布包。`capture-gt1.cjs` 检查字形、数值、固定容器、零尺寸容器、按钮相互遮挡及完整触摸轮廓的圆角安全区。

测试遮罩采用保守 100px 圆角，未将它描述为 WATCH GT 实测圆角。长文本的摘要可省略，点击后仍有原有完整动作详情。滚动列表只要求内容能完整滚入视口，不声称所有统计在同一屏展示。

## 真机验收步骤

1. 安装方屏 0.6.35（50），确认不是旧圆屏包；手机配套版本为 1.6.32（78）。
2. 概览页按住不到一秒松开、按住后轻微滑动取消，进度应归零；立即点击“放弃训练”，必须可进入确认并返回。
3. 休息中先点 ±15 或转表冠调整，再到概览持续按住至少一秒；离线与在线均应进入总结，手机重连后不重复保存。
4. 保存失败时应保留错误并能重试；“放弃训练”二次确认后返回首页。
5. 在 1:03、15:00、RPE/RIR 未填写和已填写、长动作名、下一动作、最后一组等状态检查底部组号/重量/次数；滑动翻页、评分、撤回不得失效。
6. 逐页检查首页、当前组、休息、统计各分屏、动作列表展开、键盘及错误提示、各确认层、总结滚到底部；数值、单位和触摸按钮不得被物理圆角挡住。
7. 连续切页及训练三十分钟，核对现有流畅性保持。没有真实设备数据时不填造耗时、内存、帧率或稳定性结论。

原生模拟器独立连接只收到握手、未获得页面帧，不纳入原生渲染通过证据；仍需上述真机回归。
