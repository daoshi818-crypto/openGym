# OpenGym 1.6.23 / BlueOS 手表 0.6.26

针对同一动作连续点击组圆点后卡死、黑屏退出的反馈，修正可复现的输入与渲染压力路径，不改变训练界面布局。

- 圆点使用会话、动作实例和组 ID 作为稳定节点标识；普通刷新及同动作切组只更新状态，不重建整排节点。
- 点击当前组不再写盘或生成重复的焦点同步事件。
- 连点的 120ms 安静期内只保留最后一个尚未提交的切组目标；最多一个写入在途、一个目标等待，不堆积点击任务。
- 已提交的事件不删除、不合并，继续逐事件确认与持久重试；延迟执行保留点击时的手机因果版本，手机并发修改仍优先。
- 隐藏、销毁、结束页面或更换训练时取消未提交切组；暂停、休息、删除目标后重新校验。切组尚未提交时阻止完成按钮操作旧组。
- 增加限量持久诊断日志，记录手表切组、页面生命周期、写盘耗时和同步回执/重试。连点汇总计数，最多每秒一个日志写入，单独存储，不进入训练队列。
- 手表连接、发送计划、诊断和日志导出统一到「设置 → 集成 → vivo BlueOS 手表」，移除训练设置中的重复入口，修正集成页原先误跳计时提醒的问题；不改连接面板布局。
- 面板增加「导出诊断日志」，通过系统分享导出 JSON；包括手机 SDK/同步记录、手表分页日志和环境信息。断连时仍可导出手机记录及明确标注时间的历史手表缓存。
- 手机 1.6.23 / 方屏、圆屏手表 0.6.26 配套更新，训练业务协议不变，增加独立只读日志查询命令。日志不包含完整训练内容或账号凭据，也不是 BlueOS 原生崩溃转储。

自动化验证覆盖瞬时 200 次连点、持续 1,000 次连点、重复点击当前组、慢存储、取消后重入、旧行下标和手机快照插入。它们验证逻辑和资源上界，不模拟原生渲染器。未连接物理手表、未取得崩溃日志，不能据此断言系统级黑屏退出的唯一原因或已彻底消失，仍需安装新手表包复测。

证据、实现边界与复测步骤见 `docs/dev/WATCH_SET_DOT_RAPID_TAPS_1_6_23.zh-CN.md`。
