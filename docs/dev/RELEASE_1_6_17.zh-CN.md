# openGym 定制版 1.6.17

手机 **1.6.17 / code 63**，手表 **0.6.20 / code 35**。

## 修复手表离开页面后待上传队列停住

BlueOS 的定时器随创建它的 App 或 Page 实例管理。原来发送超时、重试、积压重放和存储超时由页面创建，页面销毁后回调可能不再执行，而共享队列仍处于发送或写入中。

- 改为应用生命周期持有同步和存储定时器，切换页面继续处理待上传。
- 页面重新出现只更新订阅，不重复绑定同一个连接并发送 hello，减少反复全量同步。
- 保留逐条业务提交确认、失败退避、发送间隔、分批重放和本地持久化；不会因传输成功就删除未确认记录。
- 训练时钟读取心率小片段，避免每秒复制整个动作列表和待上传历史。

## 跳过休息与返回训练

- 修复同步队列停住导致跳过休息无法继续送达手机的路径；积压按顺序提交后，两端停止休息。
- 返回训练清理残留手势和点击屏蔽状态，防止画面显示但无法操作。
- 动作列表的保存结束使用一次返回和当前训练会话的结束请求，避免替换出多余训练页面。
- 重复点击导航入口只执行一次，结束请求只消费一次。

## 底部按钮与屏幕适配

- 返回训练、放弃训练改用明确的窄按钮样式，修正图标文字横向排列，避免并排按钮继承整行宽度。
- 保留 GT1 390×450 及圆屏布局和安全留白；继续使用内置 SVG 图标，无 emoji，也没有动作演示图片传输。

## 验证与边界

- 回归涵盖 40 条积压后跳过休息、原页面销毁、超时恢复、重复消息、旧快照、导航锁恢复及心率投影读取。
- 检查 BlueOS 编译后的方屏和圆屏模板、样式、内置图标及包版本和签名文件。
- 自动化生命周期模拟及编译验证不能代替真机测试。本次没有连接真实手表，尚不能断言所有设备上的闪退都已消除。
