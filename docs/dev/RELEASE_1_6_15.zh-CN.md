# openGym 定制版 1.6.15

手机 versionCode **61**。本次集中修复统计页布局、结构平衡中文显示和返回后的页面状态，不修改训练记录、组数、重量或结构平衡评分算法。

## 修复内容

### 统计页不再被分析卡片挤占
- 统计标题之后直接显示“训练日历 / 趋势统计”切换，默认直接展示训练日历。
- 移除切换上方重复的“每块肌肉的每周组数”和“各动作力量等级”卡片；这两项只保留在趋势内容中一份。
- “训练表现报告”入口仅在趋势统计内容中出现，切回训练日历即不可见，不在两项切换上方显示。

### 结构平衡中文显示
- 人名和体系名保留原文：Poliquin、Thibaudeau（力量举）、ATG，不进行中文音译，也不另起模板名。
- “锚点”改为“比较基准”；“临界”等状态改为“达到 / 接近 / 低于参考值”，缺少记录时明确提示需要先记录什么。
- 动作使用常见中文名称，保留 Poliquin 等专名；保留次数、自重与额外负重、哑铃单手重量等原有条件。不改变动作映射或比例。
- 简体中文结构平衡的动作副标题不再默认追加整段英文，避免中文和英文混排。
- 不改全局动作名显示设置；显式开启“仅英文动作名”时仍按用户偏好显示，自建动作保留原名，其它语言不强制隐藏英文括注。

### 返回后留在趋势统计
- 在路由中保存日历/趋势的选中状态；切换使用替换历史记录，不额外堆积返回层级。
- 从趋势进入结构平衡后，页内返回与系统/浏览器返回都回到原趋势页面；刷新趋势链接也保留选中项。
- 直接打开结构平衡时，页内返回默认进入趋势统计。
- 保留“每周肌群训练量”的直达链接；切回日历时清除该定位参数，避免又被切回趋势。

## 验证范围
- 增加真实路由返回、URL 恢复、日历/趋势入口顺序及去重、三个中文模板、自定义动作及英文偏好的自动化回归。
- 浏览器以合成训练资料检查 360、390、430 像素宽度；验证返回、刷新、报告隐藏及数据保护，无浏览器运行错误。这不等同于用户手机真机验收。
- 发布流水线仍需完整前端、API、语言包和移动启动校验通过，才构建并发布 APK，不绕过质量门禁。

## 升级说明
- 手机升级本次 APK 即可，无需删除数据或重建训练计划。
- 手表无代码变更，发布继续附带 **0.6.18 / code 33** 的方屏、圆屏包及校验文件；已安装该版手表无需重复安装。
