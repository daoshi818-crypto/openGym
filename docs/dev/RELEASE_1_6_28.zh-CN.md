## 本版修复

- 圆点切组立即呈现选中组、重量和次数，后台确认本地游标持久化；较慢写盘不再成为界面切换的前置等待。连续切组、期间点完成/撤回、页面隐藏、手机同步或存储失败时，仍核对稳定组身份和原操作意图，避免操作错组。
- 手表开练消息保留手机训练需要的完整 entries，去掉重复的手表展示数据。协商后，大事件按实际 JSON 字节数分片上行；手机原生层完整校验并写可靠 Inbox 后再处理。手表继续持有原事件，直到收到精确业务提交回执。失败、断线与手机进程重启均允许整事件重发。
- 应用销毁时关闭 RPC、取消 App 定时器、释放页面订阅和缓存、结算未确认写入，屏蔽旧实例迟到回调继续工作。磁盘训练及未确认事件保留供重开恢复。
- 手机已保存业务决策后的 Inbox 清理异步执行，避免清理桥接回调拖住进入训练与业务回执。错误日志优先显示 code 与实际包大小。

本版沿用纯 √ 完成按钮、动作列表/结束胶囊、动作名旁剩余组数及长名称展示方式。
