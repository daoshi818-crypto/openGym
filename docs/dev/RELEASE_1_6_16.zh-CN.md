# openGym 定制版 1.6.16

手机 **1.6.16 / code 62**，手表 **0.6.19 / code 34**。集中处理积压同步、手表字体图标兼容及 GT1 圆角安全区。

## 手机与手表积压同步
- 重放编辑前按 eventId 去重。已在发送队列中的记录不再重复读取、复制和写回完整训练状态。
- 恢复缺失编辑每批最多两条，批次间让出执行时间，快速点击不重复启动恢复。
- 业务消息发送至少间隔 120ms，不在 SDK 回调中递归倾倒积压；v3 仍保持队头等待业务确认。
- 手机过滤已被保存协调器认领的原生 inbox ID，合并完成后的读取，减少同批 32 条记录重复跨桥进入 JS。
- 原生 inbox 删除失败时释放认领并安排重读，重新使用已落盘的业务决定，不永久屏蔽失败记录。
- 保留持久化及精确业务回执规则：SDK 发送成功不等于手机已保存。不清空队列、不删除未确认记录。

## 手表不用 emoji
- 开始/继续使用播放三角，完成使用勾，撤销使用回转箭头，暂停使用双竖线；均为随包内置的自绘 SVG，不依赖 emoji 或图标字体。
- 返回入口使用绘制的左箭头并保留必要中文说明，保存状态使用圆形勾，退格使用绘制图标；心率、清空保留明确中文。
- 保留 CSS 绘制的结束旗帜和组圆点，不引入 emoji 字体、媒体演示或图片传输。
- 新增手表源码及编译模板的 emoji/易缺字图标检查，防止回归。

## GT1 390×450 圆角安全区
- 五页顶部关键内容留距，表头宽度限制为 314 设计像素，关键底部控件保留安全距离；页面背景仍铺满屏幕。
- 重排标题、上次记录和空隙，保留主数字、94px 完成按钮及 44px 组圆点点击区。
- 主训练、标准休息、减加编辑、精确键盘保持完整一屏；首页有最近结果入口时也完整显示首张双行计划卡。
- 无最近结果入口时单独给列表增加底距，防止动作说明被圆角裁切。
- 保留圆屏独立样式，不把方屏固定宽高套到圆屏。

## 验证边界
- 新增 40 条积压、快速连点、重复确认、离线重连、重启恢复、v3 顺序、删除失败、恢复异常回归。
- 两种手表包使用 BlueOS Studio 编译器和现有签名构建，校验编译后布局、版本、校验值。
- 32 场景浏览器预览采用保守的 80 设计像素圆角遮罩，检查初始及列表末尾的可见文字。该值不代表设备实测圆角。
- 自动化测试与浏览器预览不等同于真机验收；固件字体、真实裁切及蓝牙条件仍需设备确认。

## 升级
- 手机、手表都应升级，才能包含两端全部优化；无需清空数据或重建训练计划。
- 手表未上架官方应用商店，需使用 orbibitv 安装对应的方屏或圆屏 RPK。
