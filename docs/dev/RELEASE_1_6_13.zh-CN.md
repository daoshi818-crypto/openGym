# openGym 定制版 1.6.13

手机 versionCode 59。修复统计页重复报告入口；保留 1.6.12 的 AI 教练与键盘修复。手表代码没有变化，本次发布继续附带已发布的 0.6.18 方屏 / 圆屏包，已经安装该版本的手表无需重复安装。

## 统计页
- 移除“训练日历 / 趋势统计”切换栏上方重复的“训练表现报告”按钮。
- 保留趋势统计内原有的报告入口、设置中的报告入口及报告生成 / PDF 导出功能。
- 训练日历仍为默认视图，切换趋势统计后报告入口仍可进入 `/reports`。不修改训练数据、日历内容、其他卡片或统计计算。

## 验证
- 新增 UI 回归覆盖有计划无历史、有训练历史、无计划无历史三种情况；修复前均复现多余报告入口。
- 检查入口数量、默认日历可见性、切换趋势后报告可见性、报告导航、切回日历隐藏和数据不变。
- 本次为手机页面修正，不包含新的手表变更或服务器部署。
