# openGym 1.6.36 / WATCH GT 0.6.39

本版包含 1.6.35 / 0.6.38 的长按保存可靠性与首页连接提示修复，并补齐后台恢复和旧页面重试之间的边界。

- 一次按住期间的重复触控不会重置截止时间；进度、截止和抬手检查共同确保一秒长按仅发起一次本地保存。短按、滑动、取消和页面隐藏撤销尚未完成的长按。
- 组数据正在写盘时，结束请求进入本地串行队列；关闭前已排队的操作保留，关闭开始后不再接受新编辑。
- 本地关闭成功后进入结果页，App 后台分批补传。上传异常不会把已保存训练留在旧页面，满队列且没有进展时不进行快速空转。
- 存储收尾失败会释放保存锁并保留原始冻结记录重试；App 已在后台恢复完成时，再次保存会核对相同关闭 eventId、关闭记录和本地结果，直接进入对应结果页，不重复结束，也不把其他训练的记录当成成功。
- “手机已连接／手机未连接”仅在首页出现。训练页只保留待上传、待确认和存储错误等必要业务反馈。

手机 `openGym.apk` **1.6.36（82）**；390×450 方屏 `opengym-watch-0.6.39.rpk` **0.6.39（54）**。圆屏继续附带 **0.6.31 legacy**，不包含本次修复。请优先安装本版配套资产。

保持既有官方 Wear OS 视觉映射和正常一秒长按交互。验证与真机验收见 [WATCH_HOLD_RELIABILITY_1_6_36.zh-CN.md](WATCH_HOLD_RELIABILITY_1_6_36.zh-CN.md)。没有 WATCH GT 真机连接，不将自动回归和语义预览当成实机稳定性或帧率测试。
