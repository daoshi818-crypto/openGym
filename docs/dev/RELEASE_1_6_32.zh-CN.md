# openGym 1.6.32 / WATCH GT 0.6.35

针对 390×450 方屏的结束操作和遮挡修复。

- 修复调节休息后结束失败的异步状态问题；清理根触摸取消、松手、返回和放弃确认时的旧长按计时器。
- 按住结束保留一秒门槛，使用独立截止计时、固定触摸层及松手时长兜底；保存失败后保留提示，允许重试和放弃。
- 五页统一核对方屏安全边距与原生尺寸预算；休息页动作名、组号、重量次数分开预留空间，数字键盘及底部按钮收进安全区域。
- 保留具体手表选择、双向连接确认、完整计划目录和今日计划同步。音乐控制保持移除。

安装包：手机 `openGym.apk` 为 1.6.32（78）；方屏 `opengym-watch-0.6.35.rpk` 为 0.6.35（50），请配套更新。圆屏仍是 0.6.31（46）旧兼容包，不含此次修复。
