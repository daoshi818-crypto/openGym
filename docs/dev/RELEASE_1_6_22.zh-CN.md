# OpenGym 1.6.22 / BlueOS 手表 0.6.25

参考训记的固定命令、字段覆盖与去重证据，进一步简化普通训练操作的同步回程，保留现有界面。

- 新增双端协商的命令确认：手机将权威差量与精确业务决定一同落盘，手表应用后直接更新页面，省去每次操作单独启动状态传输。
- 操作产生时的因果版本保持不变；发包时另带实际已应用的手机基线，减少快速连续操作使用旧编码基线。
- 第一组重量/次数导致动作默认值变化时，只校正对应动作字段，无需因此回传完整动作列表。
- 消除第一组字段变化引起的页面自动计划重复发送；仅在命令落盘后去除同内容回传，保留真正计划修改与显式继续训练的确认。
- 保留逐事件去重、持久重试、手机并发编辑优先与关闭保存/放弃日志。丢包、重启、基线缺口、结构变化和旧版端保留可靠回退。
- 修复晚到快照确认使同步基线退回、持久传输恢复请求未使用手机最新训练的问题。
- 新增快速五组加两组、重启重放、存储失败、同时在途、校验失败和能力兼容回归。

固定两动作七组、第一组完成+休息的完整业务 JSON 往返由 3,599B / 9 条降为 1,599B / 3 条；相同条件改重量由 3,347B 降为 1,292B。数据含命令/确认/状态回执，不含 SDK 和无线链路开销，不代表每次操作或真机实测流量。
