# openGym 定制版 1.6.11 / vivo 手表 0.6.17

手机 versionCode 57；手表 versionCode 32。请同时更新两个端，可覆盖安装，建议先导出备份。

## GT1 390×450 手表界面重构
- 首页、当前组、休息、动作列表、数值编辑、结束确认、总结及评分/历史覆盖层统一重写；页面根容器填满屏幕，不再使用旧的 350px 固定外壳及多轮紧凑样式覆盖。
- 外观以已确认的 Apple Watch V3/V4 方屏适配稿为准：横排大数字、绿色圆形完成按钮、104px 休息倒计时、绿色旗帜结束入口、左对齐纵向滚动总结。
- 同动作组选择采用小圆点：当前组白色描边、完成组白色实心、待做组深灰。点击未完成组切换；完成组可通过动作列表查看和撤销；大量组分页，不改变当前组。
- 点击动作名打开动作列表，选择其他动作；独立展开按钮用于查看各组，避免将展开与切动作混成同一操作。
- 点选重量/次数后用表冠调值；再次点击进入显式保存/取消的编辑页，支持减加和精确键盘。训练主页的表冠调整维持原有即时保存规则。
- 标准当前组的主要操作在 390×450 一屏可见；长名称、长历史及更多操作通过原生列表滚动，不通过缩小关键数字硬塞。
- 结束旗帜先进入确认，不自动补完未完成组；总结页完成按钮仅返回首页，不再次结算。

## 移除手表动作演示
- 移除手表图片帧入口、播放器、缓存与协议处理，手机端移除 PNG 抽帧传输插件及其注册，不再占用训练同步通道传图片帧。
- 手机端原有动作视频与动作库保留。旧版本已缓存的文件不主动清除，避免触碰训练存储；不再使用或传输它们。

## 验证边界
- 本地完整前端回归 497 文件 / 6073 项通过，mobile 模式启动测试 2 项通过；手机生产 bundle、素材暂存、Capacitor 同步与 Android release Java 编译通过。
- 方屏/圆屏均使用厂商编译器构建，编译后布局合同通过；29 个代码生成 390×450 场景的边界检查通过。
- 原生方屏与圆屏构建、编译后布局合同、真实页面脚本回归和代码生成的 390×450 浏览器预览用于发布前验证。
- 浏览器预览不是手表真机截图；尚需 GT1 安装后检查固件字体、表冠事件和实际触控。不能等同于原生 Apple Watch/Wear OS 的像素级真机复刻。
