# 动作名称简体中文审校

日期：2026-10-27。范围：仅动作中文名称，不进行上游版本同步、主题移植、动作说明翻译、DeepSeek执行、安装包编译、安装、提交或推送。

## 结果与覆盖方式

- 真实动作 **5,632** 个，中文名称全覆盖；优化 **1,120** 个，其余 **4,512** 个保留。
- 全量进行中文可读性、器材/术语、变式编号和一致性扫描；对疑似体位错误、明显直译、陌生术语和名称冲突，定向核对英文名称、描述及步骤。
- 不是对5,632条动作逐个观看演示，也不是逐条完整英中语义人工对照；源文本相互矛盾的条目不凭猜测定名，见下文。
- 动作ID、别名映射、英文源、其他语言、动作说明和要领不变；没有按名称合并动作。
- 名称源：`catalogue/i18n/zh.json`；使用原生成器更新：`frontend/src/exercise-names/zh.js`。
- 完整改动列表见同目录 `EXERCISE_NAMES_ZH_CN_CHANGES.csv`（UTF-8 BOM，含动作ID、英文名、改前/改后中文名、理由；动作ID须按文本读取以保留前导0）。

## 用词准则

1. 大陆简体中文健身语境优先，兼顾动作区分；保留必要的器材、姿势、握法、方向、单/双侧和变式信息。
2. 名称大致按“器材＋姿势/限定＋动作”排列，不强行为了格式整齐重写已自然的名称。
3. `lever/leverage`器械使用“器械”，不把器械名逐字译成“杠杆式”；`long lever`另译“长力臂”，不得误当器械。
4. `plate loaded`为“挂片式”，不误写成“插片式”；Smith统一“史密斯机”。
5. 使用“EZ曲杆”“三角肌后束”“健身球”“地雷管”“臀推”“悬吊带”等常用表达。
6. 抗阻`triceps extension`采用“臂屈伸”；真实的肌肉拉伸保留“拉伸”，避免将拉伸改成力量动作。
7. `thruster`为“深蹲推举”，`renegade row`为“支撑划船”，`muscle-up`为“双力臂”；不将这些动作按字面直译。
8. `planche`与`front lever`区分“水平支撑”与“前水平支撑”，不与普通平板支撑混用。
9. 核实俯卧/仰卧/侧卧；英文`lying`本身不强行等同“仰卧”。源允许多种卧姿时使用“卧姿”。
10. `v. N`统一为“（变式N）”，按英文源保留编号，不凭中文旧编号另造变式。
11. JM、FABER等约定缩写保留，不强行音译；不把生造音译当作本土化。

以下名称仍有优化空间，但英文材料不足以可靠确定动作。它们不是已确认的最终译法；本轮保留原中文，不误改成另一个动作。

| ID | 现中文名 | 源问题/下一步依据 |
|---|---|---|
| 0240 | 绳索仰卧反向飞鸟 | 英文名为`supine`，描述/步骤却写`face down`；需演示确认体位 |
| 0059 | 杠铃仰卧牧师凳弯举 | 英文名称/描述为卧姿，步骤却要求坐姿胸贴牧师凳；不能只据步骤改成俯卧 |
| 0339 | 哑铃仰卧腿弯举 | `dumbbell lying femoral`说明包含疑似错误姿势/持重方式；需演示确认，不能直接按普通俯卧腿弯举改名 |
| 0543 | 壶铃海盗超级腿 | `kettlebell pirate supper legs`疑似源拼写问题，描述与步骤的动作模式亦不一致 |
