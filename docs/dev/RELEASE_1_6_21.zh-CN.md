# OpenGym 1.6.21 / BlueOS 手表 0.6.24

本版重整手机与手表训练同步，保留现有界面风格。

- 手机不再把空闲休息清理当作新编辑，修复手表第一次完成后回退、第二次才同步的回归场景。
- 握手后原子交付完整当前训练，避免裸计划先激活造成的首操作窗口；严格匹配快照回执。
- 持久可靠链路使用已确认基线增量，快速操作不取消在途传输；断开、重启、丢确认保留恢复能力，基线不符回退全量。
- 真正同时编辑自动以手机为准，保留逐事件落盘和精确确认，不弹冲突选择。
- 手表操作页与结束页补放弃训练及二次确认；结束页可滚动，并修局部字段、圆屏边缘与长数值裁切。
- 新增真实关闭保存/放弃、落盘失败、重复回执、启动握手及增量恢复回归。

参考方案、同步动作流程、采用/不采用的原因及可复现数据量对照见仓库 `docs/dev/WATCH_SYNC_ARCHITECTURE_1_6_21.zh-CN.md`。固定两动作七组样本，单次完成后的权威状态由 1,677B 全量改为 523B 增量；包含该状态传输分片与回执的业务 JSON 由 2,924B 减至 1,333B，非底层无线流量或整次点击全部流量。

验证范围：自动化、Android 与方/圆 BlueOS 原生构建、代码生成界面预览。未连接物理手表，系统级黑屏/死机是否消失需要设备复测；不能用预览代替真机验证。
