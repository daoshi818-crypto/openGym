# OpenGym 1.6.29 / 方屏手表 0.6.32

本次提供手机 1.6.29（75）正式签名 APK、vivo WATCH GT / BlueOS 方屏 0.6.32（47）RPK，并保留圆屏 0.6.31（46）兼容包。请同时升级手机和方屏手表，以使用新下发的肌群和出生年份数据。**圆屏未迁移本次 UI，所附圆屏包保持旧版本号和原始内容。**

## 下行通信

- 保留协商式版本化全量/delta、持久分片、最终完整性检查与原子提交；每片成功落盘后才发送确认。
- 接收进度使用最多两个任务的有界元数据缓存，恢复时重新扫描磁盘，避免每到一片就全扫描。65 片探针中，chunk 阶段读调用由 4420 次降至 195 次；这是 fake store 调用计数，不是真机耗时。
- 同会话先比较业务 commitRev，相同版本再比较已有快照时间戳，迟到旧包不能覆盖新状态，也不能成为 delta 基线。
- 已持久应用的下行在训练页隐藏时延后刷新 UI，返回页面再加载。

## 方屏界面

以官方 openGym 最新发布 v1.4.5（固定 commit `2d70e026effc6602f513555166a97443520f0572`）的 Wear OS 方屏代码为来源，中文呈现主要训练流程：概览 / 当前组 / 统计 / 媒体四页、胶囊按钮、数值框、休息条、官方 RPE/RIR 快捷项、键盘和结束统计。更完整的来源、AGPL、尺寸映射及本地保留操作见 [源码对应与验收说明](https://github.com/daoshi818-crypto/openGym/blob/v1.6.29/docs/dev/WATCH_OFFICIAL_WEAR_0_6_32.zh-CN.md)。

手机计划、快照和目录现在传递真实肌肉权重及合法出生年份，手表据此计算完成组的肌群分配和心率区间。修复暂停按钮不响应、隐藏页表冠切页、跨动作下一组号、末组评分入口及按钮对比度问题。

## 必须了解的当前限制

**这不是整套官方 UI 百分百复现完成版，也未证明设备闪退全部解决。**

- 尚未完整移植官方开始倒数、称重、计时保持、修正组、热身/单双侧/超级组状态机。
- 心率页已有真实平均/最高/最低，但完整曲线未移植；旧会话缺少的历史样本不会补造。
- 媒体控件当前不可用；BlueOS 系统媒体控制尚未完成验证。
- 使用 BlueOS 系统字体和移植尺寸，缺少同条件官方截图、动效及真机逐状态对照。
- 上一轮审计中的 legacy ACK/peerProtocol、依赖链与队列容量问题尚未全面处理。
