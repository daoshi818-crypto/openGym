# openGym 1.6.31 / WATCH GT 0.6.34

本次补齐具体手表选择、双向连接确认、全量训练计划及今日计划逻辑。手机与方屏手表请配套更新。

- 手机可选择曾与本机通信的具体手表，同名设备按标识尾号区分；发现其他手表不自动换目标。
- 分开显示运动健康通道和手表应用状态，通过本次双向探测确认连接，超时及断连不会维持在线假象。
- 提供打开 vivo 运动健康入口：现有 SDK 无法枚举全部已绑定硬件或直接切换物理通道，实际连接仍在那里选择。
- 自动发送全部训练计划，支持手动重新同步；取消原先“今日加一个额外计划”的限制。
- 今日多个计划按官方排期顺序合并；保留动作来源，今日无安排时仍可选择其他计划；跨日后旧缓存不再假称“今天”。
- 目录使用独立持久分片、校验、重试和保存确认，训练事务优先；修复已被更新快照接管的训练计划重复排队。

完整说明、协议边界和真机验收步骤见 [设备选择与目录同步记录](WATCH_SELECTION_CATALOG_0_6_34.zh-CN.md)。单个目录传输上限为 128 KiB，超限明确失败，不静默删减计划。

这不是全部官方 Wear OS UI 百分百复刻完成声明，也不代表已通过真实手表 30 分钟稳定性验收。音乐控制保持移除。
