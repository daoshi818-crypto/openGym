# openGym 1.6.37 / WATCH GT 0.6.40

针对训练中没有操作却回到表盘的反馈，加强前台显示保持、后台业务检查点和恢复流程。

- 活动训练在应用前台时申请保持亮屏，不再只在休息倒计时阶段保持。暂停、结束、冻结关闭和应用进入后台时释放；跨训练页和动作列表由同一 App 所有者管理，减少页面切换互相覆盖亮屏状态。前台训练亮屏会增加耗电。
- 使用 BlueOS 官方 schedule 注册真实流逝时间的一次性训练检查点；活动训练每次完成检查点后再注册下一次，间隔 60 秒。写入心率尾部记录、恢复通信和补传，不打开页面或抢占其他应用。暂停、关闭、超过既有六小时上限后取消或停止续约。
- 任务编号持久保存，应用重建时取消已知旧任务并恢复活动训练。任务用训练 sid、分段时间和随机 token 隔离；迟到或重复任务不能操作另一场训练。注册失败、回调丢失或存储失败会降级并记录，不在前台快速循环重试。
- 心率与通信的初始创建移至 app.ux；应用隐藏时立即请求写入心率尾部。页面销毁只释放自己的显示订阅，保留 App 通信；旧页面不能注销新页面的订阅。
- 新增 app_show、app_hide、app_error、app_destroy 与任务失败记录，帮助区分系统退到后台、应用销毁和实际错误。

安装版本：手机 `openGym.apk` **1.6.37（83）**；390×450 方屏 `opengym-watch-0.6.40.rpk` **0.6.40（55）**。圆屏仍为 **0.6.31 legacy**，不包含本次改动。

本次基于官方后台运行、定时任务和亮屏 API 实现。持续后台运行仍由系统支持的实际后台能力及固件策略决定，定时检查点不等于无限常驻。没有连接 WATCH GT 真机，不声称已经验证实机退出率、功耗或固件故障全部消失。
