## 范围与边界

本次按用户要求整理五个手表页面及训练浮层，优先解决字段、按钮互相挤压，扩大常用触区。**不构建、不升级版本、不生成或发布 APK/RPK**。0.6.28 是此前同步修复版本，不能据此认为本次新 UI 已包含在发布包中。

- 当前组、休息倒计时和重量/次数编辑均为固定一屏，模板不含滚动列表。
- 首页、动作列表、评分、历史详情、训练操作、确认和总结页面允许原生列表滚动。
- 保留主屏上次训练小字摘要、点击查看只读详情，以及原训练统计和操作入口；摘要不复制到本次记录。
- 完成/撤回、评分、编辑、暂停、保存结束及放弃确认仍调用既有处理函数；不重写同步协议、重试队列或手机权威逻辑。
- 上轮普通 Function 定时器回调包装、圆点稳定身份和休息预览校正继续保留。

## 不编译的检查方式

`scripts/source-template.mjs` 仅把当前 `.ux` 模板表达式、重复节点和向量图标转为浏览器预览树，不是 BlueOS 编译器。`preview-gt1.mjs` 默认使用当前源码；仅显式设置 `WATCH_PREVIEW_SOURCE=0` 时读取既有编译目录。

在仓库根目录生成、检查两个目标：

```powershell
node watch-app/scripts/preview-gt1.mjs <方屏输出目录>
node watch-app/scripts/preview-gt1.mjs <圆屏输出目录> watch-round
# PLAYWRIGHT_MODULE 可指定现有 Playwright 安装目录
node watch-app/scripts/capture-gt1.cjs <方屏输出目录>
node watch-app/scripts/capture-gt1.cjs <圆屏输出目录>
```

覆盖各 48 个场景：无历史/有历史、已完成/暂停、五组/七组/多组分页、长动作名/长数字、休息与评分提示、编辑键盘、结束/放弃、诊断及总结上下部分，另补重量编辑极值、保存失败提示、保存中，以及重量/次数选中边框、lb 和时长单位。几何检查包含横向溢出、数值裁切、圆角/圆形文字安全区、兄弟控件与文字相交，以及主训练/休息/字段编辑容器不得含列表。控件相交分别检查滚动顶部、中部和底部，避免只查底部漏掉顶部遮挡。

### 截图所示 kg 与数字纵向裁切

原检查只比较 `scrollWidth/clientWidth`，漏掉上下裁切。当前预览字体的 20px `kg` 自然行框为 27px，而旧单位容器仅 22px；基线与 Canvas 实际字形测量确认 `g` 尾部超过容器 2.5px。旧圆屏布局在新增检查下有 11 个场景失败。数字行框也只比字号大 0–2px，缺少安全余量。

修复保留数字字号，增加数字/单位的明确行框，字段宽度按内容区伸展，避免选中边框吞掉内容空间。新增检查通过实际基线与 `actualBoundingBoxAscent/Descent` 比较每层裁切边界，并覆盖未选中、选中和已完成状态；源码测试约束数字至少 8px 额外行高、单位完整行框和 2px 边框余量。检查先在旧源码失败，再在修复后通过。本项仍属于浏览器预览验证，不等同于原生固件验收。
