# 手表大字 UI 与防遮挡整理（2026-11-12，源码阶段）

## 范围与边界

本次按用户要求整理五个手表页面及训练浮层，优先解决字段、按钮互相挤压，扩大常用触区。**不构建、不升级版本、不生成或发布 APK/RPK**。0.6.28 是此前同步修复版本，不能据此认为本次新 UI 已包含在发布包中。

- 当前组和休息倒计时均为固定一屏，模板不含滚动列表。
- 首页、动作列表、字段编辑、评分、历史详情、训练操作、确认和总结页面允许原生列表滚动。
- 保留主屏上次训练小字摘要、点击查看只读详情，以及原训练统计和操作入口；摘要不复制到本次记录。
- 完成/撤回、评分、编辑、暂停、保存结束及放弃确认仍调用既有处理函数；不重写同步协议、重试队列或手机权威逻辑。
- 上轮普通 Function 定时器回调包装、圆点稳定身份和休息预览校正继续保留。

## 布局取舍

| 位置 | 本次处理 |
| --- | --- |
| 当前组 | 动作名两行，重量和次数分列、单位放在数字下方。普通数值方屏 56px、圆屏 52px，长数值逐级降字号。提示替换组状态行，不额外增加一行。 |
| 上次训练 | 主屏摘要保留 18px 小字，44px 点击行仍调用 `openLast`；操作页另外提供同一详情入口。 |
| 完成/撤回 | 64px 高文字按钮，保留向量图标；有 RPE/RIR 时与强度入口分配独立宽度。 |
| 组圆点 | 普通点 24px、当前点 28px，触区 48×48px。最多五组全部展示；更多组每窗三个点加前后两个按钮，总计五个触区，始终一行。翻窗不提交切组事件，选择仍保留稳定 session/entry/set ID。 |
| 休息 | 动作名两行、倒计时 88px。下一组名称/组号保留，移除重复的下一组处方数字。加减与跳过固定独立底栏，不随内容移动。 |
| 训练操作和统计 | 已用时、心率、估算热量、容量、当前处方以及加减组/暂停等操作保留。长重量与次数分别成行，避免横向挤压。 |
| 动作列表 | 动作名、组数和展开按钮分配明确宽度；组行 64px，保存/返回/放弃底栏独立固定。放弃须确认。 |
| 字段编辑 | 数字键 60px、减加按钮 64px；编辑内容可滚动，取消/保存置于滚动区外。保存中禁用重复保存，沿用原草稿校验与提交逻辑。 |
| 评分/确认/总结 | 评分大数字与大按钮；长提示、结束和放弃确认可滚动；总结单列展示，保留缺失值、同步状态与返回行为。 |

390×450 方屏的主屏预算为顶部 62px、当前组内容 312px、底栏与底部留白 70px，总计 444px。466×466 圆屏采用 300px 主内容宽与 220px 顶/底部宽，预算为 74 + 304 + 88 = 466px。圆屏尺寸及安全区均是源码预览合同，尚非真机测量结果。

## 不编译的检查方式

`scripts/source-template.mjs` 仅把当前 `.ux` 模板表达式、重复节点和向量图标转为浏览器预览树，不是 BlueOS 编译器。`preview-gt1.mjs` 默认使用当前源码；仅显式设置 `WATCH_PREVIEW_SOURCE=0` 时读取既有编译目录。

在仓库根目录生成、检查两个目标：

```powershell
node watch-app/scripts/preview-gt1.mjs <方屏输出目录>
node watch-app/scripts/preview-gt1.mjs <圆屏输出目录> watch-round
# PLAYWRIGHT_MODULE 可指定现有 Playwright 安装目录
node watch-app/scripts/capture-gt1.cjs <方屏输出目录>
node watch-app/scripts/capture-gt1.cjs <圆屏输出目录>
```

覆盖各 42 个场景：无历史/有历史、已完成/暂停、五组/七组/多组分页、长动作名/长数字、休息与评分提示、编辑键盘、结束/放弃、诊断及总结上下部分。几何检查包含横向溢出、数值裁切、圆角/圆形文字安全区、兄弟控件与文字相交，以及主训练/休息容器不得含列表。控件相交分别检查滚动顶部、中部和底部，避免只查底部漏掉顶部遮挡。
