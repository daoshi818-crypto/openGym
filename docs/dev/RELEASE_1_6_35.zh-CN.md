# openGym 1.6.35 / WATCH GT 0.6.38

重点处理长按结束训练容易停住，以及连接状态文字在训练页面反复出现的问题。

- 保留现有官方 Wear OS 视觉映射与一秒长按结束交互。一次按住期间的重复触控不会重置截止时间；截止回调、进度回调和抬手检查互相兜底，取消、滑动和页面隐藏会撤销本次长按。
- 完成组正在写入时，结束请求按本地存储队列继续执行，不再静默忽略。关闭前已排队的组操作先完成，关闭开始后拒绝新的编辑，冻结完整记录后再收尾。
- 本地关闭成功即可进入结果页，上传通过 App 后台任务分批进行；上传异常不会把已经保存的训练留在旧页面。运行中产生的新关闭日志也能补传，无需重新打开应用。
- 存储回调丢失或收尾失败时释放保存锁，显示可重试的错误。已经冻结的关闭决定和记录保持不变，重复保存复用同一条记录；未冻结的写入失败仍保留原训练与放弃入口。
- “手机已连接／手机未连接”只在首页显示。训练页正常情况下不占用状态行，仅在待上传、待确认或存储异常时显示对应反馈。
- 关闭记录每批最多入队两条，批次间让出执行；队列满且没有进展时停止快速重试，等待正常传输周期或业务回执继续，不删除待传记录。
