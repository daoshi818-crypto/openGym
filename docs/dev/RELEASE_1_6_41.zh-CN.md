# openGym 1.6.41

本版更新 vivo WATCH GT 训练连接与状态同步：手机只向已连接且就绪的手表发送当前训练计划；手表应用打开时可获取当前训练及已完成进度。训练中重量、次数和组结构采用小消息即时同步，普通状态只保留最新值；完成组使用独立事件。断连期间不建立待发送队列，重连后查询手表当前状态，不补传离线期间的组操作。

手表端更新训练状态恢复、通信拥塞处理和诊断记录，并调整表冠旋转触感为短促单次反馈。圆屏设备继续使用已签名验证的兼容版本。

手机版本：1.6.41（versionCode 89）。方屏手表版本：0.6.43（versionCode 62）。圆屏手表版本：0.6.31（versionCode 46）。

自动化验证覆盖手机与手表的当前训练启动、状态同步、断连及重连路径、表冠触感和方屏布局；发布工作流负责正式 APK 构建、签名、手表包内容校验及 SHA-256 校验。真机前台留存、内存水位和长时间训练稳定性仍需在 vivo WATCH GT 上验证。
