# openGym 手表 0.6.2

- 首页移除设置入口，优化 390×450 矩形屏居中布局与圆形图标展示。
- 训练页上下组改为箭头，已完成组支持再次点击撤销；操作页只保留加组、减组、暂停/继续。
- 动作列表页底部提供退出（放弃且不保存）与保存（结束并保存）操作。
- 休息页显示剩余时间、本轮总时长、当前动作与下一组动作/重量/次数/组号，表冠继续调整休息时长。
- 同一动作休息时只显示一次动作名，下一组只显示组号、重量与次数；更换动作时才提示下一动作。休息页关闭翻页与页码点，训练页页码点移到左上方。
- 训练主页及休息状态同时显示手表当前时间（24 小时制）和训练已用时间；暂停只冻结训练计时。
- 手表端版本：0.6.2（code 17）。

休息提示直接使用当前待做组，避免完成后游标前进导致提示跳过一组；动作名与组号、重量、次数分行显示。重新打开页面后恢复已完成动作信息。隐藏训练页不再响应表冠，操作页与暂停状态同样不会切换训练组。

验证：102 项手表相关回归测试通过，包括完成撤销、退出/保存、恢复休息提示、表冠隔离、休息禁用翻页、动作变化提示和跨午夜时钟；12 个 390×450 布局预览、官方 watch-square 编译及编译后布局检查通过。未连接实物手表，原生显示、表冠和触摸仍需真机复核。
