# opengym 手表 0.6.8

- 休息倒计时从 250ms 刷新调整为 500ms，仍保持秒级倒计时响应，减少无效整页重绘。
- 训练页时钟、已用时间和倒计时文本只有在显示内容变化时才更新，降低低功耗手表上的渲染压力。
- 表冠切换组只写入一次焦点状态，减少快速旋转时的存储写入。
- 滑动手势在移动超过 24px 后锁定横向或纵向，避免斜向滑动过程中方向改变导致切页不稳定。
