# opengym 手表 0.6.1

本次仅更新手表 RPK，手机版本仍为 1.6.2，无需更换 APK。

- 以 390x450 竖屏矩形适配，官方编译目标改为 watch-square。
- 各页面根容器填满实际视口，去除根容器固定宽高与大 padding 的组合；主要内容宽 350，横向居中，上下留 18。
- 训练页重新分配整屏空间，放大重量、次数、倒计时和按钮；心率留在底部。两页竖排圆点、右滑动作列表、上一组/下一组保留。
- 首页、动作列表、键盘、总结和确认层同步适配；圆角只避让屏幕四角。
- 手机已发起训练时，手表收到计划或快照后直接进入训练页；已存在的训练启动时自动恢复。缓存计划仍需手动开始。
- 结束/放弃及不同训练冲突仍需确认。相同训练的重发消息和原生页面生命周期不会重复跳转。

验证：95 项相关回归测试通过；14 个 390x450 布局状态完成 Playwright 预览边界检查；官方 BlueOS VRU 编译及打包清单校验通过。构建脚本增加了编译后全屏和内容边界检查。

预览以 36px 圆角进行边界检查，不代表设备的精确圆角。未连接实物手表，实际安装、原生显示和触摸仍需真机复核。

手表独立发布使用 watch-v0.6.1 标签，不替换手机更新清单或手机最新发布。
