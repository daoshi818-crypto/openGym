# openGym 手表 0.6.3

- 首页移除设置入口，优化 390×450 矩形屏居中布局与圆形图标展示。
- 训练页上下组改为“上/下”，已完成组支持再次点击撤销；操作页只保留加组、减组、暂停/继续。
- 训练页、休息页右滑进入动作列表；动作列表再次右滑打开结束面板。“完成”保存并结束，“取消”放弃且不保存，“返回”回到动作列表。动作页禁用系统默认右滑返回，滑动后短暂拦截点击，避免误触结束操作。
- 休息页显示剩余时间、本轮总时长、当前动作与下一组动作/重量/次数/组号，表冠继续调整休息时长。
- 同一动作休息时只显示一次动作名，下一组只显示组号、重量与次数；更换动作时才提示下一动作。休息页关闭翻页与页码点，训练页页码点移到右侧。
- 训练主页及休息状态同时显示手表当前时间（24 小时制）和训练已用时间；暂停只冻结训练计时。
- 训练页重量和次数仅保留数值及 kg/次单位，移除重复中文标签；“上/下”和“完成”收紧到同一行。训练页和休息页移除动作列表入口，动作列表通过右滑打开完成、取消、返回面板；页码圆点位于右侧。
- 手表端版本：0.6.3（code 18）。

休息提示直接使用当前待做组，避免完成后游标前进导致提示跳过一组；动作名与组号、重量、次数分行显示。重新打开页面后恢复已完成动作信息。隐藏训练页不再响应表冠，操作页与暂停状态同样不会切换训练组。

验证：手表相关回归测试、390×450 布局预览、官方 watch-square 编译及编译后布局检查通过。未连接实物手表，原生显示、表冠和触摸仍需真机复核。

本次仅发布手表 RPK；手机仍为 1.6.2，保留现有手机更新清单与最新发布。
