# opengym 手表 0.6.0 / 手机 1.6.2

本轮落实 `WATCH_NEXT_ITERATION_HANDOFF.md` 的训练、会话、计划与发布要求。

## 界面与操作

- 手表显示名 opengym，圆形图标，包名不变。
- 上下滑动切换训练／操作两页，右侧两个竖排圆点指示页码。
- 右滑打开动作与组列表；上组／下组和表冠只切换当前动作内的组。
- 训练页和休息页保留心率；操作页提供组数、暂停、结束与放弃。
- 按 390x450 设置边距；训练、休息、键盘、动作列表、总结及确认页完成布局预览检查。

## 数据与会话

- 导航游标独立于训练快照，忽略本机焦点回显与旧焦点。
- 重量、次数、加减组立即本地保存；未被快照确认的编辑继续重放。
- 事件使用持久 ID、字段版本和业务 ACK；断线及重启后补传。
- 本轮休息同时维护目标总时长和剩余时间；加减同时调整二者，默认休息不变。
- 结束训练提供保存、不保存和继续；放弃有独立二次确认。
- 关闭会话持久化墓碑；旧计划不能复活已结束训练。
- 手机先关闭后的手表离线保存进入手机待确认，用户确认后才更新历史；拒绝保留手机记录。
- 已保存训练续练仍覆盖原记录，累计时长和估算热量保留。
- 手表当前训练段超过六小时自动关闭并丢弃未保存增量，之前已保存的历史不删除。

## 计划与连接

- 手机发送今日计划及设置中手动选择的计划，手表缓存、浏览并可离线开始。
- 手表开始消息幂等创建同一会话；另一端已有训练时显示冲突，不自动覆盖。
- 手机正在训练的标题栏增加手表按钮，拉起后补发计划和快照，收到同场业务回执才提示成功。
- 暂停、当前休息、同步状态及最近结果接通；后台能力依赖进程与 vivo RPC 服务存活。

## 构建与验证边界

官方 blueos-pack 1.0.12-beta.13 编译 watch-round VRU RPK，脚本校验格式、版本与校验和。
GitHub 手机签名构建同时附带 RPK 和 SHA256，并在 APK 发布成功后更新 update.json。
本地已做状态／协议回归、生产构建和 HTML 布局预览；后者不能替代手表运行时。
仍需 vivo 真机复核传感器、息屏与进程被杀后的恢复、表冠手感和安装升级。

手机 1.6.2 补齐离线确认合并：保留后来新增动作、PR、肌肉快照及续练累计时长；关闭消息只发送必要字段。更新检测并行读取 CDN 与源清单，按较新版本提示更新。
